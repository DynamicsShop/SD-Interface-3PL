## SD Interface 3PL Releases

### 1.0.0

#### Enhancements

- C/AL - Initial Build.

- C/AL - 3rd Party Logistics Interface objects were created.

- C/AL - Mapping functionality and objects were created.

- C/AL - Master data functionality and objects were created.

- C/AL - Transactional Outbound Data files from NAV were created for Sales Orders, Purchase Orders, Transfer Shipments, and Transfer Receipts. Transactional Data files were presented as an ODATA Query read only.

- C/AL - Functionality and logic was created to place the Transactional Inbound Data files from WMS to NAV in a staging table.

- C/AL - Functionality for validating, testing, processing and error handling the Inbound Transactional Data from the WMS was created. Users have three options to Process, Skip or Error Reset.

- C/AL - A Role Centre for SD Stores Manager 3PL Interface was created.

- C/AL - Our standard About page was created and surfaced on the SD Stores Manager 3PL Interface Role Centre and Setup List.

- C/AL - Objects were reordered and renumbered.

- C/AL - Activity Pages for KPIs were created and added to the Role Centre.

- C/AL - Two navigation pane actions were added to the Role Centre - a Mapping action and a Master action.

- C/AL - The SD-3PL RC Activities Mappings page was removed from the Role Centre as mappings were filtered by 3PL Code.

- C/AL - Amended logic of SD-ST3PL in the Inbound page to cater for processing inbound entries with no serial numbers.

- C/AL - Added a new field 3PL Reason Code to the SD-3PL Inbound Entries.

- C/AL - Master pages were amended to be used for full or differential sequencing.

- C/AL - A datetime stamp was added to the Transactional ODATA tables.

- C/AL - Added a filterable datetime modified field to the Transactional tables.

- C/AL - Added Lot and Serial Number to the INDEX Web Services Page.

- C/AL - Standard NAV OneNote, Notes and Links were removed from the SD-3PL pages.
